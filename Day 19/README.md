# Day 19: Kubernetes Gateway API

## Objectives for Today

1. Understand what the Kubernetes Gateway API is and why it is needed.
2. Understand the main components of Gateway API.
3. Demonstrate advanced traffic management techniques, including:

   * `ReferenceGrant`
   * Traffic mirroring
   * Traffic splitting for canary deployments
